About this build

Saved videos are browser bookmarks. They save the result link and metadata on this device; they do not download the video.

Hosted collections currently use shared site storage without user accounts. Do not use private or sensitive data.

The scanner can only rank fields a source actually exposes. Missing views, likes, dates, or ratings remain unavailable.
